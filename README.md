# Chalkida Hair Bot 💇‍♀️✨

Это профессиональный Telegram-бот для парикмахерской студии в Халкиде (Греция), готовый к запуску на Hugging Face Spaces (Docker).

## 🚀 Как запустить на Hugging Face Spaces:

1. **Создайте Space**:
   * Перейдите на [huggingface.co/new-space](https://huggingface.co/new-space).
   * Выберите имя для вашего Space.
   * В разделе **SDK** выберите **Docker** (с шаблоном Blank).
   * Сделайте его **Public** или **Private** (по вашему желанию).

2. **Задайте Переменные окружения (Secrets)**:
   * Перейдите на вкладку **Settings** созданного Space.
   * Прокрутите до раздела **Variables and secrets**.
   * Нажмите **New secret** и добавьте все параметры вашего бота из файла `.env`:
     * `BOT_TOKEN` — токен вашего Telegram-бота.
     * `ADMIN_IDS` — ID администраторов через запятую (например: `123456789,987654321`).
     * `GEMINI_API_KEY` — API-ключ Google AI Studio (для ИИ-трихолога и черновиков).
     * `TELETHON_API_ID` — (Необязательно) API ID для парсера чатов.
     * `TELETHON_API_HASH` — (Необязательно) API Hash для парсера чатов.
     * `DB_URL` — (Важно!) Ссылка на вашу базу данных. 
       * *Примечание:* Так как файловая система Hugging Face сбрасывается при перезапусках, локальная база SQLite будет обнуляться. Для постоянного сохранения записей укажите здесь строку подключения к бесплатной базе данных (например, Supabase Postgres): `postgresql://user:pass@host:5432/dbname`. Если оставить пустым, бот запустится с SQLite, но данные будут сбрасываться при перезапусках.

3. **Загрузите файлы**:
   * Загрузите все файлы вашего проекта (кроме файлов `.env` и локальной папки базы данных `database/*.db`) в созданный репозиторий через Git или через кнопку **Files and versions** -> **Upload files**.
   * После загрузки файлов Hugging Face автоматически начнет сборку Docker-контейнера и запустит его!

---

## 🛠️ Архитектура бота:
* **Основная логика:** Aiogram (Python).
* **База данных:** SQLAlchemy (SQLite по умолчанию, полностью совместим с PostgreSQL).
* **Веб-сервер заглушка:** Бот автоматически поднимает легкий HTTP-сервер на порту `7860`, чтобы проходить проверку жизнеспособности (health checks) от Hugging Face.
